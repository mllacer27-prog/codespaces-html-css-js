# codespaces-html-css-js

Proyecto de ejemplo con HTML, CSS y JavaScript.

Archivos añadidos:

- [index.html](index.html)
- [styles.css](styles.css)
- [script.js](script.js)

Para probar localmente, abre `index.html` en tu navegador o usa un servidor estático, por ejemplo:

```bash
python3 -m http.server 8000
# luego visita http://localhost:8000
```
